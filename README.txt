DISPLAY MASJID MIFTAHUL JANNAH
==============================

File ini dibuat untuk tugas sekolah.

Cara membuka:
1. Extract file ZIP.
2. Buka folder hasil extract.
3. Klik 2 kali file index.html.
4. Website akan terbuka di browser.

Yang bisa kamu edit:
- Nama masjid: index.html
- Jadwal salat: index.html
- Pengumuman dan kata-kata: index.html
- Warna dan desain: style.css

Catatan:
Jadwal salat yang ada saat ini hanya contoh untuk desain tugas sekolah.
